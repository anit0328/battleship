# レーダー作戦

10×10マスのレーダー画面で、相手の部隊をさがして撃沈する対戦ゲームです。
宇宙からうつ「ソーラーレイ」は、ねらったマスから **たて1列とよこ1列ぜんぶ** に当たります。

▶ **あそぶ：https://anit0328.github.io/battleship/**

スマホでもパソコンでも、ブラウザだけで遊べます。インストールはいりません。

## あそびかた

1. **デッキ編成**：作戦室のマップをタップすると、デッキ編成がひらきます。10×10マスに自分の部隊7体をならべて「決定」を押します。
   - コマはドラッグで動かせます。
   - ダブルタップすると、向きが90度ずつまわります。
   - 「おまかせ」を押すと、自動でならびます。
2. **出撃**：対戦相手をさがします。見つからないときはCPUと対戦します。
3. **ねらって発射**：上の画面（相手のエリア）をタップかドラッグすると、十字のねらいが動きます。「発射」を押すか、同じマスをもう一度タップするとうてます。25秒たつと、おまかせで発射します。
4. こうたいで攻撃して、先に相手を **5体撃沈** したほうの勝ちです。

### ルール

- ソーラーレイは、ねらったマスから、たて1列とよこ1列のマス全部に当たります。
- 十字のまんなか（着弾点）は爆発して **2ダメージ**、ほかのマスは1ダメージです。
- 耐久値は **1マスごと** です。耐久2のコマなら、同じマスに2回当てると、そのマスがこわれます。
- コマのマスがぜんぶこわれたら撃沈です。
- 当たったけどまだこわれていないマスは「HIT」、こわれたマスは濃い赤に✕で表示されます。
- どのコマを沈めたかは、相手にはわかりません。撃沈した数だけが表示されます。
- 対戦のあとは、結果画面の「盤面を見る」で、おたがいの配置と当たったマスを見られます。

| コマ | マス | 1マスの耐久 |
|---|---|---|
| 地雷 | 1 | 1 |
| セスナ | 1 | 1 |
| ジェット | 2 | 2 |

| 潜水艦 | 3 | 2 |
| 大型船 | 4 | 3 |
| 空母 | 5 | 4 |

## そのほかの機能

- **オンライン対戦**：同じタイミングで出撃した人と、自動でマッチします。オプションでオフラインにすると、いつもCPU戦になります。
- **ずる対策**：試合のはじめに、配置を「封をした形（ハッシュ）」で送ります。終わったら答え合わせをして、うその結果を返していたら反則負けになります。
- **プレイヤーレベル**：対戦で経験値がたまってレベルが上がります。CPUはレベルが低いうちはやさしめで、負けが続くとさらにやさしくなります。
- **BGMと効果音**：オリジナルのチップチューンが、バトル中だけ流れます。音量はオプションと、バトル画面のゲージで変えられます。

### デバッグ用

URLのうしろにつけると使えます。

- `?dbg=1`：ブラウザのコンソールから `window.__ro` で中身を見られます
- `?mplog=1`：オンライン対戦の通信ログを、画面の上に表示します
